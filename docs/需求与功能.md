# 需求与功能

## 功能需求

### 1. 零食库存管理
- 零食入库：名称、数量、存放位置、购买日期、生产日期、保质期、过期日期、备注
- 保质期单位：天 / 月 / 年，1 月 = 30 天，1 年 = 365 天
- 生产日期 / 保质期 / 过期日期：任意两项自动计算第三项
- 搜索：按名称 / 备注模糊搜索
- 过滤：按存放位置筛选，支持位置自动补全

### 2. 双重状态维度
- 过期状态（过期/警戒/正常/无过期）
- 生命周期状态（未打开/已打开/已吃完），由打开日期和吃完日期自动推断

### 3. 过期提醒
- 按分级展示：已过期 / 1-3 天 / 1-7 天
- 已吃完的零食不显示在提醒中

### 4. 登录认证
- Bearer token 认证
- 退出登录、修改密码
- 过期会话清理

### 5. 管理员账户管理
- 创建 / 查看 / 删除普通账户
- 非管理员访问返回 403
- 首次启动自动初始化 admin 账户

### 6. 单进程部署
- 无中间件（无 Nginx / API 网关）
- Angular 构建产物由后端直接托管（SPA fallback）
