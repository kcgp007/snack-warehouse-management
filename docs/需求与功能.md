# 前端功能需求与验收

1. **/login**：用户名/密码登录，错误提示。
2. **/ 零食库存**（需登录）：表格列 = 名称、数量、位置、购买日期、生产日期、保质期（按单位）、过期日期、状态徽章（过期/生命周期）、打开/吃完日期、备注、操作（编辑/删除）。顶部筛选：搜索框、位置下拉（自动补全）、过期状态、生命周期筛选。表单字段含：生产日期、保质期（数值+天/月/年）、过期日期（任意两项自动计算第三项，即时提示矛盾）、生命周期状态（只读徽章，不提供状态下拉）、打开/吃完日期。建议快捷动作“标记打开”/“标记吃完”。
3. **/reminders**：按 status 分组/标色展示剩余天数。
4. **/users**（admin guard）：用户列表、添加、删除（不能删自己），非 admin 显示 403 提示。
5. **/change-password**（需登录）。
6. 导航栏：显示当前用户名、退出；库存页显示提醒角标（reminders 数量>0 红色计数）。

行为：HttpClient 统一携带 Bearer token；401 自动跳转 /login；authGuard 保护业务路由；adminGuard 保护 /users；API 基址相对路径 `/api`。构建产物可被任意静态服务器 + SPA fallback 托管。

**前端美化（v2 验收项）**：统一配色/字号/间距/圆角/阴影、表格行悬停与斑马纹、空状态加载提示、表单校验即时可见、桌面与窄屏不破版；中文文案统一。

## 位置自动补全（v2）
输入过程中按已输入字符调用 GET /api/locations?q=<文本> 回显已有位置，点击可快选；同时允许自由输入。搜索栏下拉沿用 GET /api/locations（无 q）。
