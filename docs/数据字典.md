# 数据字典

## 数据模型（SQLite）

默认数据库文件：`data/app.db`（可由 TOML 配置 `db_path` 覆盖；`data/` 已被 .gitignore 忽略）。首次启动自动建表。

### users 表
| 列 | 类型 | 说明 |
|---|---|---|
| id | INTEGER PK AUTOINCREMENT | |
| username | TEXT UNIQUE NOT NULL | 登录名 |
| password_hash | TEXT NOT NULL | argon2 或 bcrypt 哈希，禁止明文 |
| is_admin | INTEGER NOT NULL DEFAULT 0 | 0/1 |
| created_at | TEXT NOT NULL | RFC3339 UTC |

### sessions 表
| 列 | 类型 | 说明 |
|---|---|---|
| token | TEXT PK | 随机高熵 token（≥32 字节熵） |
| user_id | INTEGER NOT NULL FK→users | |
| expires_at | TEXT NOT NULL | RFC3339 UTC，默认 7 天 |
| created_at | TEXT NOT NULL | RFC3339 UTC |

删除用户时必须级联删除其 sessions。

### snacks 表
| 列 | 类型 | 说明 |
|---|---|---|
| id | INTEGER PK AUTOINCREMENT | |
| name | TEXT NOT NULL | 零食名称 |
| quantity | INTEGER NOT NULL DEFAULT 1 | 数量，≥0 |
| location | TEXT NOT NULL | 存放位置，自由文本 |
| purchase_date | TEXT | 购买日期 YYYY-MM-DD，可空 |
| production_date | TEXT | 生产日期 YYYY-MM-DD，可空 (v3) |
| shelf_life_days | INTEGER | 保质期换算后天数，0..36500，可空 (v3) |
| shelf_life_unit | TEXT NOT NULL DEFAULT 'day' | day/month/year (v3) |
| expiry_date | TEXT | 过期日期 YYYY-MM-DD，可空 |
| opened_at | TEXT | 打开日期 YYYY-MM-DD，可空 |
| finished_at | TEXT | 吃完日期 YYYY-MM-DD，可空 |
| status | TEXT NOT NULL DEFAULT 'in_stock' | in_stock/opened/finished，由 opened_at/finished_at 推断 (v3) |
| notes | TEXT | 备注，可空 |
| created_at | TEXT NOT NULL | RFC3339 UTC |
| updated_at | TEXT NOT NULL | RFC3339 UTC |

## 存量数据迁移（幂等）

- **v2**：`opened_at`/`finished_at` 截取前 10 位为 YYYY-MM-DD，非法置 NULL。
- **v3**：旧库启动补齐 `production_date`/`shelf_life_days`/`shelf_life_unit` 列（NULL, NULL, day）。

## 生产日期 / 保质期 / 过期日期联动

填任意两项自动算第三项；三项矛盾 → 400；过期早于生产 → 400；保质期不在 0..36500 → 400。支持 天/月/年 单位，写入 API 时统一换算为 `shelf_life_days`（1 月=30 天、1 年=365 天），同时保存 `shelf_life_unit`。

## 生命周期状态推断与日期校验（v3）

状态完全由日期决定：两者皆空→in_stock；仅 opened_at 非空→opened；finished_at 非空→finished。显式传入 status 与推断不一致→400；opened_at > finished_at→400。
