# 数据字典

## 表结构

### snacks 表
| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PRIMARY KEY AUTOINCREMENT | 主键 |
| name | TEXT NOT NULL | 零食名称 |
| quantity | INTEGER NOT NULL DEFAULT 0 | 数量 |
| location | TEXT NOT NULL DEFAULT '' | 存放位置 |
| purchase_date | TEXT | 购买日期 YYYY-MM-DD |
| production_date | TEXT | 生产日期 YYYY-MM-DD |
| shelf_life_days | INTEGER | 保质期天数（换算后） |
| shelf_life_unit | TEXT NOT NULL DEFAULT 'day' | 保质期单位 day/month/year |
| expiry_date | TEXT | 过期日期 YYYY-MM-DD |
| opened_at | TEXT | 打开日期 YYYY-MM-DD |
| finished_at | TEXT | 吃完日期 YYYY-MM-DD |
| status | TEXT NOT NULL DEFAULT 'in_stock' | 生命周期状态 in_stock/opened/finished |
| notes | TEXT | 备注 |
| created_at | TEXT NOT NULL | 创建时间 |

### users 表
| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PRIMARY KEY AUTOINCREMENT | 主键 |
| username | TEXT NOT NULL UNIQUE | 用户名 |
| password_hash | TEXT NOT NULL | Argon2 密码哈希 |
| is_admin | BOOLEAN NOT NULL DEFAULT 0 | 是否管理员 |
| created_at | TEXT NOT NULL | 创建时间 |

### sessions 表
| 字段 | 类型 | 说明 |
|------|------|------|
| token | TEXT PRIMARY KEY | Bearer token |
| user_id | INTEGER NOT NULL | 外键 users.id |
| expires_at | TEXT NOT NULL | 过期时间 |

## 关系
- sessions.user_id → users.id (ON DELETE CASCADE)
